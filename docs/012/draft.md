# 想法草案

在创建故事页面新增一种模式：【从设定开始】。

- 创建页默认仍展示现在的【正文 + 续写指令】模式
- 在创建新故事的页面顶部，topbar 下方，新增按钮，点击后跳转到设定列表页。
- 「设定」是可复用的。暂时不做设定内容的结构化，以文本形式存储。

## 设定列表页

- 不具有单独路由。
- 返回按钮：回到现有的创建故事模式。
- 新设定按钮：跳转到创建设定页。
- 设定列表：展示所有已保存的设定。

### 设定列表组件

- 最新创建的设定在列表顶部。
- 不支持删除，不支持编辑。
- 点击设定项，跳转设定详情页。

## 创建设定页

- 不具有单独路由。
- 返回按钮：回到设定列表页。
- 灵感输入框：多行文本输入框。离开页面时静默清空草稿。
- 主按钮：补全设定。将灵感输入框的内容发送给大模型，依据用户的输入生成一份详细的设定，普通文本格式即可。按钮在生成结束前进入 loading 状态，不可点击。开始生成后，输入框进入不可编辑状态，下方流式展示大模型输出。生成失败时展示 toast 提示，清空大模型输出，输入框恢复可编辑状态。
- 补全设定的过程不需要服务端落库。
- 补全完成后，出现保存按钮。点击后将设定保存到数据库。
- 保存成功后，跳转到"从设定创建故事页"。
- 保存失败时，不跳转页面。展示 toast 提示，清空大模型输出，输入框恢复可编辑状态。

## 从设定创建故事页

- 路由复用现有的创建故事路由，查询参数带上 mode 和设定 ID。
- 返回按钮：回到**故事**列表页。
- 展示设定内容。
- 展示开场输入框。多行文本输入框。离开页面时静默清空草稿。
- 主按钮：开场。
- 点击主按钮后，将设定内容和开场输入框的内容都发送给大模型，作为新的创建故事的输入。
- 大模型的输入展示在横向第二页，如同现有的创建故事流程。
- 首页保留展示设定内容和用户输入的开场。
- 生成失败时，删除第二页，返回第一页。toast 提示。用户可更改开场输入框中的内容。用户可重新点击开场按钮进行重试。

## 设定详情页

- 不具有单独路由。
- 返回按钮：回到设定列表页。
- 设定内容：展示设定的详细内容。
- 主按钮：从设定开始。点击后跳转到从设定创建故事页。
